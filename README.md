# Proyecto 1 - Manejo de Archivos

Santiago Batz - 1548725

## Requisitos

- Python 3
- PySide6

## Instalación

Instalar las dependencias con:

```bash
pip install -r requirements.txt
```

## Ejecución

Ejecutar el programa con:

```bash
python main.py
```

## Archivos importantes

- `data/config.json`: guarda la configuración actual.
- `data/config.bak`: guarda el respaldo de la configuración anterior.
- `data/profiles/`: guarda las fotografías de perfil.

## Funciones principales

La aplicación permite cambiar el nombre de usuario, tema, idioma, tamaño de fuente, colores y fotografía de perfil, también cuenta con manejo de errores
